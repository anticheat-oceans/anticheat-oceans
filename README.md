## Workflow

### 1) Downloading

The user clicks **Get Started** and receives the latest Ocean build directly from the website.

### 2) Scanning

Ocean processes the machine, highlights suspicious traces, and separates noise from useful evidence.

- Memory, startup entries, and recent execution traces are checked.
- Known cheat loaders are scored alongside suspicious behavior.
- Findings are grouped by severity for fast moderator decisions.

### 3) Data Review

Staff review a clean report instead of unstructured system data.

- Every detection includes a short explanation.
- Clean/suspicious/critical findings are visually separated.
- Case notes help teams keep enforcement decisions consistent.
